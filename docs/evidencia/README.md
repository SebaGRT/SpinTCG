# Evidencia del equipo

Cada integrante registra aquí su trabajo propio en `sebastian.md`, `emma.md` o `miguel.md`, y guarda las capturas en `capturas/`. El código del respaldo del kit no se registra como trabajo propio.

## Plantilla por entrada

```markdown
### 2026-10-2X · <tarea>
- Commit o PR: <hash o enlace>
- Dispositivo: <p. ej. Pixel 7 Android 15 / emulador Medium Phone API 37 / Linux>
- Pasos: 1. … 2. … 3. …
- Resultado esperado: …
- Resultado obtenido: ✓ / ✗ (detalle)
- Captura: capturas/<archivo>.png
```
